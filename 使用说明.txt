lsrael 1.39 绘制专版 · 液体玻璃

这是从提供的 1.39 源码独立整理的绘制版本。
保留人物、物资、载具、雷达和预警；追踪、自瞄、断点及游戏内存写回链路已移除。
人物掩体漏打保留在“绘制 → 信息标记 → 人物掩体漏打”，默认关闭。
开启后使用 PhysX 场景和 15 个骨骼的遮挡判断：骨骼逐段区分可见/遮挡，
头点按头部状态显示，整体角框、姓名、血条、射线按头/胸/骨盆任一可见判断。
缺失关节不参与遮挡射线；躯干关节均不可用时，以实际人物位置判断整体标记遮挡。
“设置 → 场景线框”只控制场景轮廓；人物掩体漏打可独立使用。

人物标记：细角框、轻描边骨骼、窄血条、小玻璃姓名牌、分行距离和手持信息。
配色跟随顶部全局主题，遮挡和人机使用低饱和颜色。
界面为主页/绘制/物资/设置四页；支持手指上下滚动和独立退出。
保留视频启动、玻璃界面、七套主题、3D/拆解和独立 UI 陀螺仪，陀螺仪默认关闭。
悬浮窗默认宽高缩至原自适应默认值的90%，仍可在设置中调节或双指缩放。
悬浮窗升级为双层玻璃边框、主题柔光、立体 S 标记和分层导航卡片。
本次使用更通透的液体玻璃表面，面板透出自定义图片和天气背景。
主页随机文案、功能卡片、主题选择、背景设置、数值输入和通知条统一使用透明玻璃。
弹窗去除额外的厚底色，按钮底色同步透明；关闭背景图片后仍保持玻璃表面。
文案、快捷卡片、胶囊按钮和数字键盘共用同一套填充、边缘反光与主题底色。
去掉文案专属曲线和按钮的额外阴影/渐变；背景窗口取消黑色模态遮罩，收起恢复条同样透明。
玻璃底色改为跟随主题的浅色低透明度色泽，深色主题不再使用黑色面板填充。
文案、绘制页功能行与左侧导航直接复用同一材质绘制函数；侧栏取消重复填充。
左上角标志与标题整体使用和绘制功能行相同的单层玻璃卡片；S 标志本身不再叠加底板。
收起恢复条同样只保留一层玻璃，标志不再绘制不透明渐变。
图片取消底部渐变垫层、黑色压暗与标题遮罩；预览和缩略图覆盖同一套玻璃边缘。
文字、图标和开关状态保留清晰对比，七套主题继续同步切换。
主页、绘制、物资、设置按可用视口调整比例和排布，窄屏导航与内容分别适配。
背景设置窗口和数值输入弹窗同样按当前可用分辨率调整尺寸。
本次同时修复人物漏显及骨骼异常：骨骼不可用时仍显示人物基础信息，
人物识别改为已知人物类名或骨骼、队伍、人机和血量的组合校验，
不再依赖 0x10BC / 0x10C0 的浮点值必须等于 479.5，避免速度槽差异误排除人物。
人机标志按单字节读取；失败的血量、队伍、状态不作为确定的过滤依据。
对象列表采用分块读取、前后数组头核对和去重；有效空列表立即生效。
临时视图、列表和已确认人物坐标读取失败最多回退120毫秒，回退不延长期限；
关卡、世界、自身或人物身份变化时清理对应旧数据。
俯视/翻转视角改用三维体积投影作为备用人物框，不再按旧高度公式整人拒画。
骨骼传输失败最多补读一次；PhysX 场景更新与查询同步，命中网格保持有效引用。
每两秒输出 lsrael-draw 诊断日志，包含读取失败、回退、过滤、进入绘制的人物数量及分段最大耗时。
遮挡和场景线框使用非阻塞查询，场景提交忙碌时不让界面等待，也不把忙碌误当作确认无遮挡。
PhysX 扫描过载后冷却并恢复探测；无效实例的自动重试限频，手动初始化仍立即执行。
场景读取校验数组数量、地址范围、地形采样和三角形索引，失败数据不进入场景构建。
场景对象仅在完整读取并生成有效网格后确认加载；失败时保留旧网格并在后续扫描重试。
枚举未完成时不删除旧场景，仍有失败对象时不推进本轮时间戳；已成功对象避免重复构建。
物理读取与线框显示采用不同上限，512×512及1024×1024地形布局通过兼容检查。
线框每帧最多尝试4000个三角形，异常投影不送入界面绘制。
触摸设备异常采用退避或退出，清理本设备按下状态并保留其它设备触点；槽号越界直接丢弃。
退出时先停止并等待触摸线程再关闭设备，镜像状态更新用非阻塞互斥避免并发修改。
缺失头部/脚踝时使用有效关节和人物根坐标回退，异常单点不再吞掉整个人物框。
读取失败、无效变换、越界索引及镜头后方关节均隔离，保留真实组件平移和双脚高度。
趴姿连线按人物二维范围判断，不再仅按站立高度过滤。
没有实测依据的重复关节映射不会猜测替换；这些关节在取得有效映射前可能不画。
人物掩体漏打功能保留；PhysX 实例偏移更新为用户提供的 0x175E6D98。
启动驱动选项只保留 1=TWT、2=RT。TWT 读取接口对接用户提供的 kernel.h；
RT 延续原有 socket + ioctl 601 的读取协议，已移除 DEV、HK、QX 的连接代码。
PhysX 场景和人物绘制使用同一所选驱动的读取入口。
“绘制 → 辅助视图 → 迫击炮落点”独立开关默认关闭，可随绘制配置保存。
开启后显示主题色落点标记、距离和 XYZ 世界坐标；读链失败或投影不可用时不画旧点。
坐标链为 libUE4.so:bss + 0x42DAA8 → 0x18 → 0x9C8 → 0xE24。
末级以完整命名链的 0xE24（3620）为准，未使用原文截断的数字362。
BSS 使用驱动查询或 RT 的模块映射解析，不与模块相对地址 0x17A14AA8 重复相加。
坐标和 PhysX 偏移均来自用户提供的数据，当前只完成模拟读链及编译验证。
功能行显示选中侧边标记，开关增加立体滑块和勾选反馈。
“减少动态效果”开启后光效保持静止，陀螺仪仍需手动单独开启。
点击悬浮窗左侧“背景空间”卡片，在独立窗口中实时调整背景。
新增轻雪、细雨、星野、流萤、极光、纯净和自定义背景。
内置用户提供的三张图片：星眸、泡影、蓝蝶，在“背景空间 → 场景 → 内置图片”直接选择。
三张原始 JPEG 已嵌入可执行文件，无需额外复制图片；支持固定使用或勾选加入自动轮换。
内置图片按原比例居中铺满面板，不拉伸；宽高比例不同时会裁去超出面板的部分。
图片场景默认静态，保留主题玻璃遮罩和亮度调节，不额外叠加天气。
原始图片及生成脚本位于 app/jni/assets/backdrops；改图后运行 generate_presets.py 再重新编译。
支持固定背景、勾选场景轮播、自定义渐变和 PNG/JPEG 图片背景。
背景只在悬浮窗内部显示，可调整动态、轮播间隔与视觉强度。
固定天气场景仍播放动画；“动效”页可暂停、调密度、速度、玻璃雾度及风向。
自动轮换仅使用勾选的内置场景，间隔可调；自定义图片或渐变使用固定模式。
“自定义”页可跟随全局配色或选择上下渐变色，并为图片叠加天气。
图片用文件列表选择，支持中文路径；最大32MB、最长边8192像素，加载后缩放至2048。
背景设置关闭时保存。收起悬浮窗或开启“减少动态效果”后暂停背景动画。
背景设置窗在3D与拆解状态下仍保持平面，内容区可上下滑动。

Android 编译
  需要 Python 3 和 Android NDK r26d；输出 ABI arm64-v8a，最低 API 31。
  在项目根目录执行：
    python build_android.py --ndk D:/Android/android-ndk-r26d
  或设置 ANDROID_NDK_HOME 后执行：
    python build_android.py
  脚本自动复制到 ASCII 临时目录全量编译，默认 D:/work-build/lsrael-draw-only-139。
  可用 --stage-root 指定其他 ASCII 路径；新产物写入 build 目录。

手机运行
  此 .sh 后缀文件实际是 ELF 程序，请直接执行。
  将文件放到 /data/local/tmp/lsrael_DrawOnly_1_39.sh 后，在 root 终端执行：
    chmod 755 /data/local/tmp/lsrael_DrawOnly_1_39.sh
    /data/local/tmp/lsrael_DrawOnly_1_39.sh
  按终端提示选择 TWT 或 RT 驱动和显示模式，再在主页初始化绘制。
  选择的驱动需要已经安装并正常运行；程序本身不安装驱动。

Windows 预览与检查
  双击 preview/SpatialPreview.exe 打开玻璃界面，可切页、换色、滚动和切换3D。
  预览只访问本地演示状态，不读取游戏、驱动或手机。
  重新编译/检查需要 Zig 0.13.0：
    powershell -ExecutionPolicy Bypass -File preview/verify.ps1 -Zig D:/Tools/zig/zig.exe
  参数 --scene 由 SpatialPreview.exe 导出七套主题的人物模拟图。
  export_pngs.py 使用 Pillow 将 PPM 与保留透明通道的 TGA 转为 PNG。
  透明图总览使用棋盘格衬底展示透明效果，原始 PNG 保留真实透明通道。
  所有新 .inl、单元测试源码、验证日志与当前截图原件一并提供。
